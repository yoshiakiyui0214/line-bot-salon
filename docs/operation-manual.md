# LINE公式アカウント Bot 運用マニュアル(オーナー様向け)

このマニュアルは、スマートフォンで読みながら操作できるように作っています。
わからない言葉が出てきたときは、このページの一番下の「困ったときは」をご覧ください。

---

## このBotができること

お客様がLINEで質問を送ると、あらかじめ登録した「よくある質問(FAQ)」の内容だけを見て、
Botが自動で返信します。

**大事なポイント**
- Botは、登録していない内容については絶対に自分で考えて答えません。
- 答えがわからない質問には「店舗に直接お問い合わせください」と案内します。
- Botの自信がなさそうな返信をしたときは、オーナー様のLINEに自動で通知が届きます(詳しくは後述)。

1. スマートフォンやパソコンのブラウザで、次のURLを開きます。

   ```
   https://line-bot-salon-six.vercel.app/admin
   ```

2. IDとパスワードの入力画面が出ます。

3. 担当者から共有されているIDとパスワードを入力します。
   (このマニュアルには載せていません。紛失した場合は担当者にご確認ください)

   - ID: ______________
   - パスワード: ______________

4. ログインすると、上部にメニューのタブが並んだ画面が開きます。

   [ここにスクリーンショット]

   - **FAQ管理**:よくある質問の登録・編集
   - **メニュー・料金管理**:施術メニューと料金の一覧(※注意点は下記コラム参照)
   - **会話ログ**:お客様とBotのやり取りの記録
   - **お知らせ配信**:LINE友だち全員へのメッセージ配信

## FAQ(よくある質問)を追加する方法

お客様からよく聞かれる質問と、その正しい答えをここに登録すると、Botがその内容で返信できるようになります。

1. 管理画面上部の **「FAQ管理」** タブを開きます。(ログイン直後の画面と同じです)

   [ここにスクリーンショット]

2. 右上の **「+ 新規追加」** ボタンを押します。

   [ここにスクリーンショット]

3. 入力欄が表示されるので、以下を入力します。

   - **質問**:お客様が聞いてきそうな質問を入力(例:「駐車場はありますか?」)
   - **回答**:その質問に対する正しい答え(例:「近隣に提携駐車場がございます。詳しくはお電話にてご案内いたします。」)
   - **カテゴリ(任意)**:分類のメモ。空欄でも問題ありません。
   - **表示順(任意)**:数字を入れると一覧での並び順を調整できます。空欄でOKです。
   - **公開する**:チェックが入っていると、この内容がすぐBotに反映されます。チェックを外すと、登録だけして一時的にBotには使わせない、ということができます。

   [ここにスクリーンショット]

4. 一番下の **「追加する」** ボタンを押せば完了です。

**反映のタイミング**:保存すると、次にお客様が質問してきたときからすぐにこの内容が使われます。特別な作業(再起動など)は不要です。

### FAQの編集・削除

1. **「FAQ管理」** の一覧画面で、直したいFAQの **「編集」** を押すと、内容を修正できます。

   [ここにスクリーンショット]

2. 不要になったFAQは **「削除」** を押すと消せます。押すと確認のメッセージが出るので、間違いがないか確認してから進めてください。この操作は元に戻せません。

   [ここにスクリーンショット]

### 注意:「メニュー・料金管理」ページについて

「メニュー・料金管理」タブにも施術メニューや料金を登録できますが、
**現時点ではこの内容はBotの返信には使われません**(社内の一覧表として見るためのページです)。

料金やメニューについてBotに答えさせたい場合は、そのメニュー・料金の内容を
**「FAQ管理」のほうにも** 質問と回答の形で登録してください。
(例:質問「カットの料金はいくらですか?」/回答「カットは¥4,500です。」)

## お知らせを配信する方法

LINEを友だち登録してくれている方全員に、一斉にメッセージを送ることができます。
**送信すると取り消せません。** 送る前に内容をよく確認してください。

1. 管理画面上部の **「お知らせ配信」** タブを開きます。

   [ここにスクリーンショット]

2. 入力欄に、配信したい文章を入力します。

   [ここにスクリーンショット]

3. **「確認画面へ」** ボタンを押します。

4. 確認画面が表示され、「友だち全員に配信されます。送信後は取り消せません。」という注意書きと、入力した文章がそのまま表示されます。

   [ここにスクリーンショット]

   - 内容を直したいときは **「戻る」** を押して入力画面に戻れます。
   - 間違いがなければ **「配信する」**(赤いボタン)を押します。

5. 「配信が完了しました」と表示されれば送信完了です。画面の下に配信した日時と内容の履歴が残ります。

   [ここにスクリーンショット]

**配信前チェックリスト**
- 誤字脱字がないか
- 日付や金額が正しいか
- 「今すぐ送っていい内容か」(営業時間外の配信で問題ないかなど)

## Botが変な返答をしたときの対処法

### まず知っておいてほしいこと

Botは質問への自信の度合いを内部で「高・中・低」の3段階で判定しています。
自信が「低」だった場合は、**その場でオーナー様のLINEに自動で通知が届きます**。

通知が届いたら、以下の手順で対応してください。

### 対応の手順

1. 通知のLINEメッセージに、お客様の質問内容とBotが実際に返した答えが書かれています。まずそれを確認します。

2. 管理画面の **「会話ログ」** タブを開くと、お客様ごとのやり取りが一覧で見られます。気になるお客様をタップすると、そのお客様との会話全体が確認できます。

   [ここにスクリーンショット]

3. Botの返信の下に「確信度: 高/中/低」と表示されています。これを見ると、どの返信がBotの自信のない回答だったかがわかります。

   [ここにスクリーンショット]

4. 原因を確認します。だいたい次のどちらかです。

   - **FAQに載っていない質問だった** → 新しくFAQを追加すれば、次回からは正しく答えられるようになります。(「FAQを追加する方法」を参照)
   - **FAQはあるが、答えの内容が古い・間違っている** → そのFAQを編集して正しい内容に直します。

5. FAQを直したら完了です。再起動や特別な作業は必要なく、直した内容は次の質問からすぐに反映されます。

### それでも解決しない・様子がおかしいとき

- Botがまったく返信しない、エラーのような返信が続く場合は、FAQの内容の問題ではなく、システム側の不具合の可能性があります。担当者に連絡してください。
- お客様への個別対応(電話や個別メッセージでのフォロー)が必要と判断した場合は、通知に書かれている質問者の情報をもとに、通常の接客対応と同じようにご対応ください。
